# SEO-Audit – co2kostenberechnung.de – 04.11.2026

## Scope

Audit and non-production fixes in the isolated `seo-audit-2026-11` branch.
The `main` branch, STRATO hosting configuration and live website were **not changed**.

## Confirmed technical findings

1. The Vite React SSG route filter in `vite.config.ts` only contained root with a slash, while child paths were listed without leading slashes. The revised route filter accepts both path conventions.
2. The build did generate HTML documents, but the published source had no mechanism to transfer `react-helmet-async` metadata into the generated HTML head. A production build on this audit branch initially showed missing titles, descriptions and canonical links on all five SSG pages. The build now injects metadata from the original per-page SEO components.
3. The canonical URL for the draft partner landing page was malformed because a full absolute URL was passed to a component that already prefixes the domain. The path is now site-relative and the draft has `noindex`.
4. Calculation results are user-specific. Result views are marked `noindex` in the interactive SEO component. Client-side navigation must still be checked in the production deployment; never assume JavaScript-rendered noindex is a substitute for server-side treatment.
5. The public `robots.txt` allows crawlers and points to a sitemap containing five intended public routes. The sitemap itself was not altered.
